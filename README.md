# FoodBridge – Food Redistribution System

A responsive front-end prototype for connecting surplus food donors with NGOs, volunteers, and communities.

## Features
- Food donation form
- Available food listings
- Food request interaction
- Dashboard statistics
- Responsive design
- LocalStorage support for demo donations

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Upload the project to GitHub and enable **Settings → Pages → Deploy from branch → main → /root**.
